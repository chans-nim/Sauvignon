# 테마 분류 감사 보고서 (2026-10-23)

## 결론

현재 분류는 스키마와 참조 무결성은 정상이나, 테마 점수 산출용 분류로는 조정이 필요하다.
특히 모든 종목을 거의 하나의 테마에 강제 배정한 구조, 중분류별 표본 크기 격차,
사업영역과 맞지 않는 일부 배정이 RS·Breadth·ThemeScoreV2의 비교 가능성을 낮춘다.

## 테마 구조 개편안

### 1. 반도체

현재 `반도체소재`에 PCB·패키지기판 업체가 섞이고, `비메모리/팹리스`에 유통·후공정 업체가 포함된다.

- 메모리
- 파운드리/팹리스
- 장비
- 소재/부품
- PCB/패키지기판
- OSAT/테스트
- 인터페이스/소켓

PCB/패키지기판 분리 우선 검토 대상: 삼성전기, LG이노텍, 이수페타시스, 대덕전자,
심텍, 코리아써키트.

### 2. IT/플랫폼

`SW/AI` 218종목과 `인터넷/플랫폼` 94종목은 내부 사업모델 차이가 너무 크다.

- 인터넷플랫폼
- 기업용 SW/IT서비스
- AI 소프트웨어
- 보안
- 결제/핀테크
- 디스플레이/전자부품

### 3. 인프라

통신 서비스와 통신 장비, 유틸리티와 물류를 분리한다.

- 건설
- 건자재
- 전력·가스 유틸리티
- 물류
- 통신 서비스
- 통신 장비

### 4. 금융

- 은행
- 보험
- 증권
- 카드/여신
- 핀테크/결제
- 리츠/인프라펀드
- 금융지주

금융지주와 일반 지주사의 처리 기준도 통일해야 한다. 현재 KB금융은 은행,
BNK금융지주와 JB금융지주는 지주사로 분류돼 일관성이 없다.

### 5. 소비재·자동차·K-컬처

- 소비재에 가전/전자와 자동차 유통을 추가한다.
- 완성차에는 실제 OEM만 유지하고 케이카·도이치모터스는 자동차 유통으로 이동한다.
- F&F처럼 패션과 K-컬처 노출이 함께 있는 종목은 패션을 주분류로 두고 검증된 경우만 복수 배정한다.

## 점수 계산에 미치는 영향

1. 종목 RS는 동일 중분류 안의 백분위이므로 이질적인 종목이 섞이면 대장주 선정이 왜곡된다.
2. 2~7종목인 소분류는 한 종목 움직임이 Breadth를 크게 바꾼다.
3. 100종목 이상인 대분류는 실제 테마가 강해도 상승 종목 비율이 희석된다.
4. 잘못 배정된 대형주는 시총가중 RS와 대표 거래대금을 동시에 왜곡한다.
5. 복수 사업 대형주를 하나의 테마에만 배정하면 관련 테마의 시가총액과 거래대금이 누락된다.

## 적용 순서

1. 고확신 오분류와 금융지주 기준을 먼저 수정한다.
2. 물류, 카드/여신, 디스플레이, PCB/패키지기판, OSAT를 신설한다.
3. SW/AI, 자동차부품, 정유/화학, 의료기기, 제약, 음식료 대형 그룹을 세분화한다.
4. 변경 전후 최소 20거래일을 병렬 산출해 순위 안정성·회전율·다음날 수익률을 비교한다.
5. 검증 후 새 분류에 별도 버전을 부여하고 한 번에 전환한다.

분류 변경 전후 점수는 직접 비교하지 않는다. 테마 구성원과 백분위 모집단이 바뀌므로
전환일을 히스토리 단절점으로 기록해야 한다.
